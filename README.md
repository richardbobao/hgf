# 📚 Boletim Escolar Online

Sistema web simples e responsivo desenvolvido com **HTML5, CSS3 e JavaScript**, criado para visualização e cálculo de informações escolares de alunos.

## 🚀 Funcionalidades
- **Exibição de Dados e Notas**: Tabela com disciplinas, notas por bimestre e situação final.
- **Cards de Resumo**: Destaque para médias e frequência do aluno.
- **Calculadora Automática**:
  - Cálculo de média aritmética das notas.
  - Verificação de situação (Aprovado, Recuperação ou Reprovado).
  - Cálculo de frequência escolar (%).
- **Layout Responsivo**: Adaptado para computadores, tablets e celulares.

## 🛠️ Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Flexbox, CSS Grid e @media queries)
- JavaScript Vanilla
